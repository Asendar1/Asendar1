## ⚡ Projects

### [FEXER](https://web.fexer.asendar.me) — Live MENA Job-Search Platform
A live job board with an application tracker, built end-to-end.
- **3,600+ roles** aggregated from Greenhouse, Lever and Ashby APIs plus RemoteOK/Remotive, refreshed every 15 minutes
- React 19 + TypeScript client with search, filters and pagination; FastAPI ingestion service behind it
- PostgreSQL (Supabase) with a deny-by-default row-level-security model (guest device ID or Clerk JWT)
- CI/CD: GitHub Actions → multi-stage Docker → Heroku for the API, Cloudflare Pages for the client

### [r/place Clone](https://github.com/Asendar1/r-place-clone)
Real-time collaborative canvas supporting **5,100+ concurrent WebSocket connections** on 3 cores / 1GB RAM.
- 12-shard hub architecture (goroutines, channels, RWMutex, atomics)
- Custom 4-byte binary protocol, about 80% less bandwidth than JSON
- Redis BITFIELD (u4): 1M pixels in about 500KB, O(1) updates
- Load-tested with a Python asyncio suite simulating 5,100+ concurrent writers

### [MiniShell](https://github.com/m-darawsheh/minishell)
A Bash-like shell written in C from scratch (team of 2): pipes, redirections, expansions, built-ins, signal handling, and a custom lexer and parser, checked with Valgrind.
